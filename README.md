# Sewer Concrete Corrosion: Interpretable Machine Learning

This repository contains the code and data associated with the study:

**Predicting and Interpreting Sewer Concrete Corrosion under Limited Data Using an Averaging-Strategy-Based Interpretable Machine Learning Framework**

The study develops and evaluates an interpretable machine learning framework for predicting concrete corrosion initiation time and corrosion rate under sewer environments, with particular attention to limited experimental datasets and field validation.

## Repository Contents

### `CODE/`

This folder contains the Python scripts and supporting files used for data analysis, machine learning modelling, model interpretation, and field-data evaluation.


### `DATA/`

This folder contains the datasets used in the analyses presented in the study.


## Reproducibility

The repository is provided to support transparency and reproducibility of the analyses reported in the associated study.

The code is organized according to the main analysis stages. Supporting Excel files used by individual scripts are included where applicable.

Because some analyses involve repeated train/test splits and model optimization, the results may depend on the specified random seeds, software versions, and computational environment.
